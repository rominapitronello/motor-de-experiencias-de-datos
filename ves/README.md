# ves/ · Visualization Experience Spec

**Pluma: Sol · pendiente.**

La VES es el contrato que se puede auditar entre la pregunta y el render. Recorre estas etapas: pregunta → qué se puede responder y qué afirmaciones soporta → tarea cognitiva → patrón didáctico → vínculo con los datos → codificación e interacción → privacidad, procedencia y accesibilidad → renderer. Si una VES no valida, no se dibuja nada.
