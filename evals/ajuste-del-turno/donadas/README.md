# Preguntas donadas

Preguntas que personas escribieron para esta evaluación, con sus palabras y sin ayuda de un modelo, y que aceptaron que se usen sin su nombre. Son las únicas con garantía de no estar en ningún corpus de entrenamiento anterior a su fecha: forman el conjunto que cuenta para medir. Los ítems hechos sobre foros públicos (`ITEMS_v0`) quedan como conjunto de desarrollo.

Cada archivo guarda el texto tal como llegó, la fecha, cómo se pidió y una clasificación propuesta que todavía no revisa nadie. No se guarda quién la mandó: solo un número de donante y lo mínimo para describir la muestra.
