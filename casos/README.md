# casos/ · casos de prueba

**Pluma: Sol · pendiente.**

Son preguntas reales, pero desidentificadas o sintéticas. Cada una trae la VES esperada y sus criterios de falla. Sirven para comprobar si un cambio en el grafo o en la skill empeora el juicio.

Protocolo propuesto: correr las mismas preguntas en dos linajes (Claude y Sol) y separar dos tipos de diferencia:
- **Procedimental** (la tarea o la especificación salen distintas): el schema o la taxonomía están mal.
- **De juicio o estética**: son opciones que vale la pena conservar.

Las trampas de `trampas/` también se convierten en casos: una fuente con contenedor comunal, un índice con cuartiles invertidos, un proxy que parece hecho.
